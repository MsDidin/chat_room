# 聊天室应用

一个简单但功能完整的多人实时聊天室应用，基于 Node.js、Express 和 Socket.io 构建。

## 功能特性

- ✅ 多人实时聊天
- ✅ 历史消息记录（最多保留100条）
- ✅ 在线用户列表
- ✅ 用户加入/离开通知
- ✅ 正在输入提示
- ✅ 消息时间戳
- ✅ 响应式设计
- ✅ 美观的渐变UI界面

## 技术栈

**后端：**
- Node.js
- Express
- Socket.io

**前端：**
- HTML5
- CSS3
- JavaScript (原生)
- Socket.io Client

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

```bash
npm start
```

或者使用开发模式（自动重启）：

```bash
npm run dev
```

### 3. 访问应用

在浏览器中打开：
```
http://localhost:3000
```

## 使用说明

1. **加入聊天室**
   - 在登录页面输入你的昵称
   - 点击"加入聊天室"按钮

2. **发送消息**
   - 在底部输入框输入消息
   - 按 Enter 键或点击"发送"按钮发送消息

3. **查看在线用户**
   - 左侧边栏显示所有在线用户
   - 你的昵称会标记为"(我)"

4. **查看历史消息**
   - 新用户加入时会自动加载最近的100条历史消息

## 环境变量

可以通过环境变量 `PORT` 自定义服务器端口：

```bash
PORT=8080 npm start
```

默认端口为 3000。

## 核心功能说明

### 历史消息存储
- 服务器在内存中存储最近100条消息
- 新用户加入时自动接收历史消息
- 包括聊天消息和系统通知

### 实时通信
- 使用 WebSocket 协议实现实时双向通信
- 所有用户即时接收新消息
- 显示用户输入状态

### 用户管理
- 自动管理在线用户列表
- 用户加入/离开时发送系统通知
- 实时更新在线人数
